## 📌 Current Project

### 🔹 Handwritten Digit Recognition using CNN

A Convolutional Neural Network (CNN) built from scratch to classify handwritten digits (0–9) using the MNIST dataset.

### 📊 Results
- ✅ Validation Accuracy: **99.26%**
- ✅ Epochs: **10**
- ✅ Dropout: **0.5**
- ✅ Framework: TensorFlow & Keras
